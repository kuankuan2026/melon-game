# 三關試玩的流程骨架

範圍為幼苗期、抽藤期、授粉期。表內順序依現行畫面由上而下，供後續介面與美術製作使用。角色出場規劃依品牌設定。

| 畫面 | 用途 | 畫面元素（由上到下） | 按鈕與去向 |
|---|---|---|---|
| 開局 | 選品種或續玩 | 植日生標題、三關說明、定植月份、品種清單、操作列。除錯模式另顯示測試季節 | 選品種留在開局。開始種瓜 → 幼苗期時期卡。繼續上次試玩 → 存檔畫面，若在遊戲中途則從該遊戲的說明開始 |
| 時期卡 | 交代栽培階段及當前植株 | 金幣、三關進度、階段名稱、植株與三條狀態、階段文字、操作列 | 開始這個階段 → 首個工作，若觸發警訊先到補救 |
| 工作關 | 做固定工作或選擇處理方式 | 金幣、進度、植株與狀態、工作標題、說明、選項與費用 | 開始工作或選可玩的方案 → 小遊戲前說明。略過、授粉方式選擇等直接結算 → 工作結算。金幣不足時對應選項停用 |
| 小遊戲前說明 | 告知目標與操作 | 金幣、進度、階段／玩法名稱、操作提示、開始按鈕 | 開始 → 小遊戲。若從 Boss 登場進入，開始後到 Boss 戰 |
| 小遊戲 | 對田間或打工任務計分 | 金幣、進度、玩法標題、計時／分數與操作區。打工題組使用各自的題面和按鈕 | 點按、拖曳或使用題面按鈕。達成目標、作答完成或時間到 → 小遊戲結算 |
| 小遊戲結算 | 回報表現與農務影響。直接選擇也使用此頁 | 金幣、進度、工作名稱、分數（有玩法時）、狀態箭頭、冠冠小教室、操作列 | 繼續或自動推進 → 下一工作／Boss 登場／階段結算。遇警訊或失敗先轉相應頁 |
| Boss 登場 | 說明對手與血量變動原因 | 金幣、進度、警示、立繪、名字與台詞、血條、血量原因、操作列 | 開始戰鬥可略過登場演出 → Boss 的小遊戲前說明 |
| Boss 戰 | 操作本階段最後一個小遊戲 | 金幣、進度、階段與 Boss 名稱、血條、時間與分數、操作區、命中或失誤提示 | 依玩法點按或拖曳 → 擊敗／逃走過場；過場顯示立繪、台詞和剩餘血量，時間到或按跳過演出 → Boss 結算 |
| Boss 結算 | 顯示戰果與植株影響 | 金幣、進度、Boss 名、分數、評語、剩餘血量、狀態箭頭、冠冠小教室。授粉關另顯示著果結果 | 階段結算 → 檢查健康後進階段結算、補救或失敗 |
| 階段結算 | 比較前後植株，回顧選擇 | 金幣、進度、階段標題、前後植株、目前狀態與箭頭、最有利及最不利的決定、冠冠評語、生長勢上限提示 | 下一關 → 下一張時期卡。抽藤結束後自動帶過摘心期。授粉完成按看試玩結果 → 試玩結束或未著果失敗 |
| 補救 | 讓玩家處理本局唯一一次低值警訊 | 金幣、進度、警訊標題、植株與狀態、低值項目、葉面積或生長勢上限說明、額度提醒、選項 | 有可回復的生長勢或根系時可付費；僅葉面積偏低可略過。兩種選擇都消耗額度 → 返回該流程後續，若仍達失敗條件則轉失敗 |
| 失敗 | 交代失敗原因及本局決定 | 金幣、進度、原因標題、植株、冠冠小教室、著果狀態、數值變化、決定排名、操作列 | 從該階段開頭重來 → 該階段時期卡（每局一次，保留補救已用狀態）。重新開始 → 開局 |
| 試玩結束 | 呈現成功著果與三關總回顧 | 金幣、進度、著果標題、帶小瓜的植株、三關完成提示、著果狀態、數值變化、決定排名、正式版預告 | 重新開始 → 開局 |

四位角色的介面分工為瓜吉帶開局與時期卡旁白，歡茄在高分結算加油，櫛客提醒步驟與分析失敗，蒜淘帶打工與 Boss 暖場，冠冠負責小教室。冠冠的採收評鑑 Boss 屬正式版。
