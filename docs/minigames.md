# 三關試玩小遊戲

代碼對照 `stage-trial/gameData.js`、`game.js` 與 `mini.js`。同一工作的多種玩法依已設定順序輪替，除草則依草量切換。

| 代碼 | 用在哪一關 | 操作方式 |
|---|---|---|
| `lime/paint` | 幼苗 1-1／FZ-1 翻土拌肥 | 按住並掃過畦土格。 |
| `seed/order` | 幼苗 1-2 定植 | 依編號點穴位。 |
| `seed/memory` | 幼苗 1-3 補苗 | 記住亮起位置及順序，提示消失後依序點回。 |
| `snail/find` | 幼苗 1-4 抓蝸牛 | 點標出蝸牛的格子。 |
| `snail/flash` | 幼苗 B-1 蝸牛大王 | 按住拖動光圈，在暗處尋找並照到蝸牛。 |
| `vine/trail` | 抽藤 3-1 引蔓上網 | 沿亮點向上拖動，按順序經過藤位。 |
| `vine/timing` | 抽藤 3-1 藤夾卡位 | 指針進綠區時點一下。 |
| `vine/order` | 抽藤 3-1 由下往上綁 | 依序點編號藤位。 |
| `vine/find` | 抽藤 3-1 找出垂下的藤 | 點未固定的垂藤。 |
| `vine/balance` | 抽藤 3-1 扶正瓜藤 | 點左右調整，讓指示留在移動綠區。 |
| `prune/slice` | 抽藤 3-2 摘側芽 | 掃過側芽格，避開主蔓。 |
| `prune/memory` | 抽藤 3-2 摘側芽 | 記住順序再點回。 |
| `prune/order` | 抽藤 3-2 摘側芽 | 依編號點剪枝位置。 |
| `prune/find` | 抽藤 3-2 摘側芽 | 點出漏剪的側芽。 |
| `feed/scale` | 抽藤 3-3／FZ-3 秤肥配重 | 點 1、2、4 單位勺累加，達指定重量後送出，可重秤。 |
| `bud2/avoid` | 抽藤 B-3 徒長藤魔 | 點剪側芽，保留主蔓與結果枝。 |
| `fruitTip/cut` | 授粉 5-2 結果蔓摘心 | 看準剪刀指針，在綠區點按。 |
| `fruitTip/order` | 授粉 5-2 結果蔓摘心 | 按編號點摘心位置。 |
| `feed/timing` | 授粉 5-3／FZ-4 倒肥停手 | 在綠區點按停手。失手也算一次操作。 |
| `poll/wire` | 授粉 B-5 落花風妖，人工授粉 | 從左側花粉起點按住，沿路線拖向右側雌花；碰邊需回起點。 |
| `bee/catch` | 授粉 B-5 落花風妖，放蜂 | 左右拖蜜蜂接花粉，避開農藥滴。 |
| `plane/plane` | 共用 C-1 放天敵。設定表寫 `plane/pest0～2` | 拖動飛機，自動射擊蟲王，避開飛行干擾。 |
| `protect/paint` | 共用 C-1 用藥、非農藥資材；C-2 用藥 | 按住掃過葉背格。 |
| `mildew/find` | 共用 C-2 摘病葉、通風 | 點有白粉病斑的葉片。 |
| `homeWeed/find` | 共用 C-3 除草 | 找出並點草格。 |
| `homeWeed/slice` | 共用 C-3 除草 | 拖過雜草，避開瓜苗。 |
| `homeWeed/paint` | 共用 C-3 除草 | 按住掃過工作格。 |
| `homeWeed/avoid` | 共用 C-3 除草 | 點雜草目標，避開非目標格。 |
| `homeWeed/trail` | 共用 C-3 除草 | 照亮點順序拖過走道。 |
| `job/job` → `M-1` | 共用 C-5 鋤草 | 在雜草格往上滑拔草，避開瓜苗。 |
| `job/job` → `M-2` | 共用 C-5 採小黃瓜 | 點剛好與過老的瓜，小瓜留在藤上。 |
| `job/job` → `M-6` | 共用 C-5 市場理貨 | 看出貨單，點指定蔬果。 |
| `job/job` → `M-7` | 共用 C-5 蔬果箱打包 | 記住品項與數量，點加號配貨後交貨。 |
| `job/job` → `M-8` | 共用 C-5 幫鄰田巡田 | 記住病斑葉格，提示消失後點回。 |
| `job/job` → `M-9` | 共用 C-5 市場找零 | 依收款與售價點正確找零。 |
| `job/job` → `M-10` | 共用 C-5 數瓜入庫 | 看瓜籃，記住瓜數並選答案。 |
| `job/job` → `M-11` | 共用 C-5 裝箱拼圖 | 旋轉兩格貨品，點空箱格放置，可按送出。介面寫可拖動，現行輸入只接了點格。 |

施肥先選肥料袋再進對應玩法。消毒、授粉方式及補救屬選擇項目。生長期與主蔓摘心期沿三關交辦帶過。
